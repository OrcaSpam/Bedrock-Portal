# 🌐 Bedrock Portal

**Bedrock Portal** is a lightweight, free tool for macOS that allows you to effortlessly join custom Minecraft Bedrock servers (such as Donut SMP) on your **PlayStation 5**. 

Since Sony doesn't provide a native way to enter custom server IPs, Bedrock Portal acts as a local proxy on your Mac, broadcasting the server directly to your PS5!

---

## 🚀 How to Install and Use

1. **Download the app:** Go to the [Releases](https://github.com) section on the right side of this page and download the latest `.zip` file for macOS.
2. **Extract the file:** Double-click the downloaded `.zip` file to extract the `Bedrock Portal (v.**)` application.
3. **Same Network:** Make sure both your PC / Laptop and your PS5 / Xbox are connected to the **same Wi-Fi/network connection**.
4. **Launch Bedrock Portal:** Open the app, enter your desired Server IP (e.g., `donutsmp.net`) and Port (default is `19132`), and click **Start Proxy**.
5. **Join on your PS5 / Xbox:** 
   * Launch Minecraft on your PS5 / Xbox.
   * Navigate to the **Worlds** tab.
   * Wait patient for the server to pop-up above the other worlds.

---

## ⚠️ Important Notes

* **Keep the app running:** Bedrock Portal acts as an active bridge between your PS5 / Xbox and the server. **Do not close the app** while playing, or you will be disconnected from the server on your PS5 / Xbox!
* **Mac Firewall / Permissions:** Because the app forwards network packets, the system may ask for permission to allow incoming network connections upon first launch. Make sure to click **Allow**.
* **Wi-Fi Isolation:** If the server doesn't appear at all, verify that your router does not have "AP Isolation" (client isolation) enabled. This setting must be turned off for local devices to communicate with each other.
